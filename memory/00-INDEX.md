# 인덱스 — jobRadar

세션이 바뀌어도 프로젝트가 스스로를 설명하도록 두는 파일들.

## 파일 맵

| 파일 | 역할 |
|---|---|
| [CHECKPOINT.md](./CHECKPOINT.md) | **현재 상태.** 항상 최신. 30초 안에 복귀하기 위한 문서 |
| [HANDOFF.md](./HANDOFF.md) | **다음 세션에 대한 지시.** 읽은 세션이 실행하고 **즉시 삭제**한다 |
| [checkpoints/](./checkpoints/) | 지난 체크포인트 아카이브 (추가 전용, 파일명순 정렬) |

## 프로젝트 문서

| 파일 | 역할 |
|---|---|
| [../기획.md](../기획.md) | 최초 기획 초안 (요구사항의 출처) |
| [../세부기획서.md](../세부기획서.md) | **설계 원본.** 아키텍처·DB·크롤러·알림·운영·마일스톤 M0~M12 |
| [../docs/M0-checklist.md](../docs/M0-checklist.md) | 외부 계정·API 키 발급 절차와 진행 상태 |
| [../AGENTS.md](../AGENTS.md) | 에이전트용 작업 규칙 (Codex/Claude 공통) |
| [../README.md](../README.md) | 프로젝트 소개, 실행 방법, 마일스톤 진행 상태 |

## 읽는 순서

새 세션이라면:

1. `HANDOFF.md`가 있으면 읽고 → 실행하고 → **삭제**
2. `CHECKPOINT.md`로 현재 상태 파악
3. `AGENTS.md`로 작업 규칙 확인
4. 해당 마일스톤 구간만 `세부기획서.md`에서 발췌해 읽는다 (전체 1,400행이라 통독하지 말 것)
