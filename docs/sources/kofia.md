링크 대신 `seq`만 가진 안정적인 상세 URL을 저장하며, 상세 페이지·첨부 파일은 수집하지 않는다.

## robots·접근 결과

- `https://www.kofia.or.kr/robots.txt` 요청은 robots 지시문이 아닌 일반 HTML을 반환했다.
  즉 해당 경로에서 별도 robots 정책을 확인할 수 없었다.
- 공개 목록 페이지는 식별 User-Agent로 HTTP 200을 반환했다. 명시적 금지 경로를 추측하거나
  로그인·첨부 다운로드·상세 페이지 반복 요청은 하지 않는다.
