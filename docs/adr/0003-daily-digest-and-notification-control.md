# ADR-03 — KST 09:00 일일 요약과 수신 제어

- 상태: 채택
- 날짜: 2026-08-23

## 맥락

수집은 여러 소스에서 주기적으로 일어나므로 매분 알림을 보내면 카카오톡과 브라우저 알림이 과도하게
늘어난다. 반대로 사용자는 필요할 때 방금 수집한 공고를 즉시 확인할 수 있어야 한다.

## 결정

워커는 `Asia/Seoul` 기준 매일 09:00에 한 번만 신규 매칭 공고를 채널별 배치로 발송한다. 대상
범위는 지난 24시간으로 잡고 DB의 `(job_posting_id, channel)` 유일성 제약으로 중복을 차단한다.
관리 UI의 수동 발송은 cron·방해금지 시간을 우회한다. `app_settings.notifications_enabled`는
카카오톡과 Web Push의 채용공고 자동·수동 알림을 함께 켜고 끈다.

## 결과

일상적인 알림은 예측 가능하게 하루 한 번만 도착하며, 사용자는 필요한 경우에만 즉시 발송한다.
알림을 끈 상태에서는 워커와 수동 요청 모두 전송을 시도하지 않는다. 수집 장애 같은 운영 경고는
채용공고 요약과 목적이 달라 기존 즉시 Web Push 정책을 유지한다.
